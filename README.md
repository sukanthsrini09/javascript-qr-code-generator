# QR Code Generator 🔲

A simple and responsive **QR Code Generator** built using **HTML, CSS, and JavaScript**.

This project allows users to enter text or a URL and instantly generate a QR code. The generated QR code can also be downloaded as a PNG image.

## 🚀 Features

* Generate QR codes from text or URLs
* Simple and clean user interface
* Responsive design
* Enter key support for generating QR codes
* Download generated QR code as PNG
* Clear button to reset the generator
* Input validation for empty text

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* QR Server API

## 📂 Project Structure

```text
javascript-qr-code-generator/
│
└── index.html
```

## ⚙️ How It Works

1. Enter text or a URL in the input box.
2. Click **Generate QR Code**.
3. The application creates a QR code using the QR Server API.
4. The QR code is displayed on the page.
5. Click **Download QR Code** to save the QR code as a PNG image.
6. Click **Clear** to reset the input and QR code.

## 🔗 API Used

This project uses the **QR Server API** to generate QR codes.

The entered text or URL is sent to the API, which returns the generated QR code as an image.
